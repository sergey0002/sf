# 📚 Глоссарий терминов SDD

> Полный каталог сущностей с форматами и ссылками — [[Справочник сущностей]].

## A–D

- **ADR** (Architecture Decision Record) — запись архитектурного решения: контекст, решение, последствия. См. [[ADR]].
- **BPMN** — Business Process Model and Notation (OMG): стандарт описания бизнес-процессов. См. [[Стандарты описания флоу]].
- **DFD** — Data Flow Diagrams: потоки данных между процессами. См. [[Стандарты описания флоу]].
- **EPC** — Event-driven Process Chains (ARIS). См. [[Стандарты описания флоу]].
- **AGENTS.md** — универсальный файл инструкций для AI-агентов. См. [[Инструкционные файлы агентов]].
- **ATDD** — Acceptance Test-Driven Development: приёмка ведётся от примеров. См. [[Сценарии приёмки]].
- **BDD** — Behavior-Driven Development: поведение от примеров. См. [[Feature Files]].
- **BRD** — Business Requirements Document. См. [[BRD]].
- **ConOps / OpsCon** — Concept of Operations: как система будет использоваться. См. [[SRS]].
- **Constitution** — принципы проекта. См. [[Конституция]].
- **Contracts** — машиночитаемые интерфейсы (OpenAPI). См. [[Контракты]].

## E–M

- **Delta Specs** — дельты требований ADDED/MODIFIED/REMOVED. См. [[Delta Specs]].
- **Diátaxis** — фреймворк структуры документации: tutorial, how-to, reference, explanation.
- **Docs-as-code** — документация как код: Markdown + Git + PR + CI.
- **EARS** — Easy Approach to Requirements Syntax. См. [[EARS-требования]].
- **Feature Files** — .feature файлы Gherkin. См. [[Feature Files]].
- **FRD** — Functional Requirements Document. См. [[FRD]].
- **Gherkin** — язык сценариев Given/When/Then. См. [[Сценарии приёмки]].
- **INVEST** — критерии качества user story: Independent, Negotiable, Valuable, Estimable, Small, Testable.
- **Living Documentation** — документация, генерируемая из исполняемых сценариев.
- **MADR** — Markdown Architectural Decision Records. См. [[ADR]].
- **MOC** — Map of Content: карта навигации хранилища. См. [[Главная]].
- **MoSCoW** — приоритезация: Must, Should, Could, Won't.

## N–S

- **NFR** — Non-Functional Requirements. См. [[Требования]].
- **OpenAPI** — стандарт описания HTTP API. См. [[Контракты]].
- **PRD** — Product Requirements Document. См. [[PRD]].
- **Proposal** — намерение изменения (OpenSpec). См. [[Proposal]].
- **Quickstart** — сценарии валидации для ручного теста. См. [[Quickstart]].
- **Research** — исследование технологий для плана. См. [[Research]].
- **RFC / Design Doc** — предложение дизайна с ревью. См. [[RFC Design Doc]].
- **SRS** — Software Requirements Specification. См. [[SRS]].
- **Steering** — контекстные файлы проекта (Kiro). См. [[Steering]].

## T–Z

- **Tasks** — декомпозиция плана в задачи. См. [[Задачи]].
- **Traceability** — трассируемость требований. См. [[Матрица трассируемости]].
- **ТЗ** — техническое задание (ГОСТ 19.201-78). См. [[ТЗ по ГОСТ 19]].
- **Vibe Coding** — разработка «по ощущению» без спеки; антипод SDD.
- **Wikilink** — ссылка вида `[[Страница]]` в Obsidian.
