# 📚 Глоссарий терминов субагентов

> Полный каталог сред — [[Справочник сред]].

## A–D

- **Agent Teams** — независимые сессии, коммуницирующие друг с другом (Claude Code). См. [[Claude Code]].
- **delegate_task** — инструмент делегирования Hermes: list/steer/stop субагентов. См. [[Hermes]].
- **Dynamic Workflows** — скриптовая оркестрация многих субагентов (Claude Code). См. [[Claude Code]].
- **Handoff** — передача результата между субагентами. См. [[Контекст и handoff]].
- **Hub-and-Spoke** — оркестратор в центре, субагенты-специалисты по краям. См. [[Паттерны оркестрации]].

## E–M

- **Kanban** — доска координации мультиагентов (Hermes). См. [[Hermes]].
- **Kilo Swarm** — общая доска находок субагентов (Kilo Code). См. [[Kilo Code]].
- **Max Spawn Depth** — глубина рекурсии субагентов. См. [[Hermes]].
- **Max Concurrent Children** — лимит параллельных субагентов. См. [[Hermes]].
- **Mode (primary/subagent)** — режим агента OpenCode. См. [[OpenCode]].

## N–S

- **Output Normalization** — единый формат вывода субагентов. См. [[Контекст и handoff]].
- **Profile** — профиль агента Hermes: модель, память, инструменты, скиллы. См. [[Hermes]].
- **SOUL.md** — файл личности/характера агента Hermes. См. [[Hermes]].
- **Skill Bundle** — YAML-группа скиллов за одной slash-командой (Hermes). См. [[Hermes]].
- **Subagent** — дочерний агент с изолированным контекстом. См. [[Паттерны оркестрации]].
- **Task Tool** — инструмент запуска субагентов (Claude Code, Kilo, OpenCode). См. [[Claude Code]].

## T–Z

- **Worktree** — git worktree: изолированная копия репозитория для параллельных агентов. См. [[Изоляция и worktrees]].
- **Three-Strike Circuit Breaker** — стоп после трёх одинаковых ошибок (oh-my-hermes). См. [[Hermes]].
