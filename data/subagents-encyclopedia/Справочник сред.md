# 📚 Справочник сред

> Сравнение пяти агентных сред по субагентам и скиллам. Детали — в документах [[Hermes]],
> [[Kilo Code]], [[Codex]], [[OpenCode]], [[Claude Code]].

## Сводная таблица

| Среда | Субагенты | Скиллы | Оркестрация | Изоляция |
|---|---|---|---|---|
| **Hermes** | delegate_task, live steer/stop, background | Иерархия: config→SOUL→AGENTS→профили→скиллы; скиллы создаёт сам агент | Hub-and-spoke, Kanban, Worktree Mode | Профили (память/модель/доступ), worktrees |
| **Kilo Code** | Нативная делегация через task tool; custom subagents | Skills + pipeline skills | Agent Manager, Kilo Swarm | Git worktrees, Agent Manager tabs |
| **Codex** | Встроенные default/worker/explorer; TOML-агенты | .agents/skills/, $имя, авто-выбор | /agent threads, tmux, worktrees | Sandbox policy, threads |
| **OpenCode** | @general, @explore; mode primary/subagent | Skills + agents в .opencode/agents/ | Task tool, глубина 2 уровня | Tools/permissions per agent |
| **Claude Code** | Task tool, Agent Teams, Dynamic Workflows | .claude/skills/, preloaded skills в субагентах | Sequential/parallel/hierarchical | Fresh context, worktrees |

## Ключевые отличия

| Вопрос | Ответ |
|---|---|
| Где живёт скилл | Hermes: иерархия с SOUL.md и профилями; Codex: .agents/skills/; Claude Code: .claude/skills/; OpenCode: .opencode/; Kilo: .kilo/skills/ |
| Кто создаёт скиллы | Hermes: сам агент (процедурная память); остальные: человек/команда |
| Как назначаются субагенту | Claude Code: поле `skills:` во frontmatter; Hermes: профиль + bundle; Codex: TOML + AGENTS.md; OpenCode: tools/permissions; Kilo: agents.json |
| Глубина рекурсии | Hermes: max_spawn_depth (настраивается); OpenCode: 2 уровня; Claude Code: вложенные деревья |
| Модель субагентов | Все: отдельная модель на агента (дешёвые исполнители) |
