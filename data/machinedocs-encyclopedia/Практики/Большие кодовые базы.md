# Большие кодовые базы

> [!info] Определение
> Контекст-инжиниринг для monorepo и миллионных кодовых баз: иерархические
> context-файлы, lazy loading, бюджеты токенов, ContextOps. Агент не тонет
> в контексте. См. [[Codified Context (3 яруса)]], [[Навигация по коду]].

## Стандарт / источник

- Anthropic 7-strategy framework; Packmind ContextOps; VS Code context hierarchies.
- Claude Code: 80.8% SWE-bench; hierarchical CLAUDE.md; agentic search.

## Иерархическая архитектура контекста

| Уровень | Файл | Загрузка |
|---|---|---|
| Home | ~/.CLAUDE.md | Все сессии, global preferences |
| Root | /repo/CLAUDE.md | Repository-wide conventions |
| Subdirectory | /src/CLAUDE.md | Component-specific, merges locally |

**Lazy loading**: child-файлы грузятся только при работе в директории.
Сотни KB frontend-инструкций не инжектятся в backend-задачу.

## Фреймворк WHAT / HOW / WHY / FEEDBACK

| Компонент | Содержание | Зачем |
|---|---|---|
| WHAT | Stack, структура, архитектура | Карта кодовой базы |
| HOW | Команды, конвенции, паттерны | Как работать |
| WHY | Решения, ADR, причины | Почему так устроено |
| FEEDBACK | Тесты, линтеры, гейты | Проверка результата |

## 5 анти-паттернов контекста

| Анти-паттерн | Симптом | Лечение |
|---|---|---|
| Acronyms без правил | «Follow SOLID» без конкретики | Конкретные правила, а не аббревиатуры |
| Ambiguous specificity | «2-space indentation when required» | Однозначные формулировки |
| Stale documentation | Устаревшие паттерны | Версионирование, ревью при изменениях |
| Context overload | Падение качества вывода | Token quotas, только actionable |
| Дублирование | Одно правило в 5 файлах | Single source of truth |

## ContextOps (Packmind)

- Стандарты как пакеты: packmind.json per directory (frontend → /frontend, backend → /backend).
- Версионирование и распространение через Git PR workflow.
- Pre-commit enforcement; multi-repo и monorepo.

## Правила масштабирования

1. **Token budget per context file** — как quality gate.
2. **Subdirectory scoping**: старт сессии внутри /packages/auth-service, а не в корне.
3. **Context exhaustion >50%**: деградация; `claude project purge` для сброса кэша.
4. **Структура контекста = структура кодовой базы**: один файл на модуль.
5. **Monorepo**: один канонический набор инструкций на верхнем уровне + subdirectories.
