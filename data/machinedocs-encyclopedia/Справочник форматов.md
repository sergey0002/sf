# 📚 Справочник форматов

> Каталог машиночитаемых форматов документации для агентов. Детали — в страницах разделов.

## Таблица форматов

| Формат | Назначение | Стандарт | Страница |
|---|---|---|---|
| llms.txt | Курируемый индекс сайта для LLM | llmstxt.org (Jeremy Howard) | [[llms.txt]] |
| llms-full.txt | Полный текст документации | Конвенция Vercel | [[llms.txt]] |
| AGENTS.md Index | Lazy-load индекс документов репозитория | agentsmd/agents.md | [[AGENTS.md Index]] |
| YAML Frontmatter | Метаданные документа | OKF / code-docs schema | [[Frontmatter-схемы]] |
| OKF | Портативный формат знаний | Google Cloud Platform | [[OKF (Open Knowledge Format)]] |
| OpenAPI / JSON Schema | Контракты API и данных | OpenAPI Initiative / JSON Schema | [[OpenAPI и JSON Schema]] |
| Markdown (structured) | Атомарные факты, явные связи | Конвенция AI-native docs | [[Структурированный Markdown]] |
| Mermaid | Диаграммы как код | Mermaid.js | [[Mermaid-диаграммы]] |

## Когда какой формат

| Задача | Формат |
|---|---|
| Агент должен найти документацию сайта | llms.txt |
| Агент должен загрузить документацию целиком | llms-full.txt |
| Агент работает в репозитории | AGENTS.md Index + frontmatter |
| Документация как база знаний | OKF |
| Контракты API/данных | OpenAPI / JSON Schema |
| Архитектура и потоки | Mermaid |
