# Моделирование сквозных сценариев А–Г и таксономия режимов отказа `F1–F14`

> [!abstract] Кратко
> Пошаговое моделирование четырёх производственных сценариев (от коварного багфикса и кросс-доменного эпика до холодного старта на `1M LOC` и реального контура владельца **`PHP / Laravel B2B CRM ~3 500 файлов / ~450K LOC` на Windows-хосте**) в связке с полной матрицей **14 классов отказов `F1..F14`** доказывает: переход к `sf v3.0` (`Трек А + Трек Б`) сжимает расход токенов с `50K–254K+` до **`5.8K–10K` токенов за задачу** и устраняет лазейки самообмана слабых моделей.

## 1. Сценарий А: Коварный баг граничного условия в базе на `500 000 LOC` (масштабированный кейс `UI-0011`)

*Условие:* при отказе закрытия родительской задачи из-за отсутствующей папки подзадачи команда обязана вернуть JSON `CliEnvelope` с кодом `1`, не изменив ни байта на диске.

| Показатель прогона | `sf v0.2.0` (факт `seesionaudit.md`) | `OpenSpec` (`/opsx:propose → apply → verify`) | `sf v3.0` (субагенты / капсулы + граф + оракул) |
|---|---|---|---|
| **Обращения / ходы LLM** | `75–97` ходов моночата | `12–20` ходов | **`2–4` узких изолированных вызова** |
| **Расход токенов** | `254K` новых (`7.3M` кумулятивных с кэшем) | `58K–90K` | **`~5 800–9 500` суммарно** (`0` схем MCP у слабой модели!) |
| **Покрытие комбинации `(--json × commit × missing_subtask)`** | **Пропущена** (plain text при `--json`, нет теста в `doc/tests/`) | Высокий риск пропуска (тест и код пишет одна сессия без DMN) | **Гарантировано:** матрица факторов `*.flow.json` + `Red` тест до кода + `RO Trust Zone` + `100% Diff-Mutation Kill` |

---

## 2. Сценарий Б: Кросс-доменный эпик с декомпозицией и параллельными воркерами (`1M LOC`)

*Условие:* механизм паузы/отмены задач с каскадной блокировкой зависимых карточек и идемпотентностью вебхука внешнего трекера (`UI-0033`).
1. **Intake & Collision Check (`0` чтения кода моделью):** проверка пересечений по `ENT-task-record` и символам графа с `Validity L1` / `task_leases` открытых задач до старта планирования.
2. **Архитектурная дельта (`planner / Architect`, `~7.5K` ток.):** формирование `flow-delta.json` + декомпозиция на 3 непересекающихся по записи пакета (`Wave 1: 0001 || 0002`, `Wave 2: 0003`) с проверкой отсутствия скрытых связей через граф вызовов.
3. **Параллельное исполнение слабыми моделями в изолированных `worktree`:** через `Kilo Agent Manager` (или `sf run --waves`) от зафиксированного SHA родителя с распаковкой предсобранного `.codebase-memory/graph.db.zst` и разведением портов/БД.
4. **Поочерёдная интеграция:** `diff-panel → gate → compare_graphs → flow delta apply → merge`.

---

## 3. Сценарий В: Холодный старт на чужом недокументированном монорепозитории `1 000 000 LOC` (`Go + TS + PostgreSQL + K8s`)

1. **Первичный индекс за `5–15 секунд` (`0` токенов LLM):** `codebase-memory-mcp` сканирует все языки, HTTP/gRPC/GraphQL роуты и K8s-манифесты в `.codebase-memory/graph.db.zst`; `colbymchenry/codegraph` включает `codegraph_explore` и `affected`; `rtk` сжимает выводы тестов на `80–90%`.
2. **Режим `Touch-to-Codify` (`Progressive Brownfield Ratchet`) на первой задаче (`src/billing/refund.go`):** описывать весь миллион строк не требуется — инспектируется только маршрут `POST /v1/refunds → ProcessRefund` и его `1-hop` соседи (`~450` ток.), синтезируется `refund.flow.json` со статусом `candidate`, правка проходит `RO Trust Zone` + дифф-мутатор, оставляя первый верифицированный островок канона.

---

## 4. Сценарий Г: Реальный продуктовый контур владельца (`PHP / Laravel B2B CRM`, `~3 500` файлов / `~450K LOC`, Windows-хост) + ночная смена и `Cold Resume`

1. **Работа на Windows без обрыва:** в Трек А (0-diff CLI) `.kilo/setup-script.ps1` готовит окружение Windows нативно, а write-вызовы `arch` идут через `wsl python3` до двухдневного фикса `F0` (`python -m arch gate` + кроссплатформенный лок в `fs_atomic.py`).
2. **Микро-багфикс НДС в PDF для дробного количества (`Quick Profile` на слабой модели):** карточка `≤1 КБ` с полем **`unchanged_behavior`** (*«для целых количеств и нулевого НДС расчёт побайтно идентичен»*), `locator` через `codegraph_explore` / `codebase-memory-mcp` (Hybrid LSP PHP + роуты Laravel) собирает `envelope` (`~1.2k` ток.), `oracle-keeper` через `codegraph affected` пишет падающий тест `Pest/PHPUnit`, `implementer` правит 1 файл (`~3k` ток.), `verifier` на другой модели проверяет функцию по 4 вопросам Winninger → **`~9–10K` токенов за всю задачу вместо `50K–70K`!**
3. **Ночная смена на `20` подзадач («Акт сверки») с обрывом на `#14` и `Cold Resume`:**
   - Цикл `Ralph loop` крутится внутри **5-контурного sandbox'а** (`Kilo /sandbox` + контейнерный `egress allowlist`), карточки ведутся со связкой `state.json + events.jsonl` и JSON-флагами `"passes": false` (по протоколу Anthropic).
   - При холодном перезапуске после обрыва на `#14` система **не перечитывает корпус**, восстанавливает проекцию через `arch task replay`, запускает **принудительный входной smoke-прогон** по закрытым `#0001..#0013` и выдаёт ровно один следующий шаг `#0014`.

## 5. Матрица закрытия всех 14 режимов отказа агентной разработки (`F1..F14`)

| Код | Режим отказа (`Failure Mode`) | Статус в `sf v0.2` (`as-is`) | Чем закрывается в `sf v3.0` (`Трек А + Трек Б`) |
|---|---|---|---|
| **`F1`** | Тихая подмена `intent` / `scope` самим агентом | `intent_digest` в `0/77` задач (`PROB-20`) | Автогенерация `intent_digest` при `task new` (`F0`) + отказ гейта при расхождении |
| **`F2`** | Исполнение по устаревшему плану после смены контракта соседом | **Нет** (`PROB-09`) | `Validity L1` (`task snapshot / audit / impact`, где `unknown ≠ current`, этап `F2`) |
| **`F3`** | Ложный рапорт «Готово» (`self-report`) | Проза в `verification.json`, `23/29` без `approvals` | Строгая JSON Schema `result ∈ {pass, fail, not_run}` + `Independent Verifier` + блок `approvals` |
| **`F4`** | Тесты цементируют фактическое багованное поведение | **Нет** (`PROB-02`) | `Oracle-First (Red до кода)` + `RO Trust Zone` + `Diff-Mutation Gate` (`Infection`, `mutmut`, `Stryker`, `cargo-mutants`, `PIT`) |
| **`F5`** | Преждевременная остановка / потеря памяти длинной смены | **Нет** | JSON-реестр `passes: false` + `events.jsonl` replay + обязательный входной smoke-прогон |
| **`F6`** | Повреждение состояния при сбое записи | Журнал есть, `state.json` не подключён | Кроссплатформенный атомарный журнал + автоподключение `state.json` / `events.jsonl` |
| **`F7`** | Запись мимо разрешённых файлов (`scope creep`) | Только прозой в карточке | FS allowlist прав субагента `implementer` + контейнерные/`bwrap` RO-маунты |
| **`F8`** | Prompt-injection из текста внешней Jira-задачи | Декларация в Манифесте | Изоляция недоверенных полей тикета без прав переопределения policy + блок сетевого эксфильтрата |
| **`F9`** | Утечка секретов / несанкционированный сетевой egress | **Нет** (только запрет словами) | 5-контурный sandbox с `egress allowlist` и подачей секретов только через прокси/ephemeral env |
| **`F10`** | Конфликты параллельных подзадач в одной ветке | Дети пишут в ветку родителя | Волны `waves` / `Kilo Agent Manager` + per-child ветки и `worktree` с разведёнными портами/БД |
| **`F11`** | Деградация внимания от переполнения контекста (`Context Rot`) | **Усугубляется** (`~25K` вход + монолиты `52K`) | `Envelope ≤2k` + `Context Compiler ≤6k` + граф `Graphify` + сжатие корпуса на `−80%` + `RTK` |
| **`F12`** | Блуждание слабой модели по большой базе (`grep`-паралич) | **Нет** (`PROB-04`) | Гибридный срез `colbymchenry/codegraph` + `codebase-memory-mcp` (`0` MCP-схем у `implementer`) |
| **`F13`** | Падение записи и локального гейта на Windows владельца | **Блокер** (`fcntl`, `bash/tar`, `PROB-22`) | Кроссплатформенный лок в `fs_atomic.py` + `python -m arch gate` + `.kilo/setup-script.ps1` |
| **`F14`** | Тихий дрейф между документацией и реальным кодом | Флаги `implemented` без сканера кода | Сверка `symbol_bindings` ⋈ граф кода + детерминированные `analyze/converge` + периодический аудит `CodePrizm` |
