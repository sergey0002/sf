# Подключаемые графы кода, `Graphify`, аудит `CodePrizm`, компрессоры `RTK/Headroom` и нормализация `Findings`

> [!abstract] Кратко
> Разработка кастомного MCP-сервера снята с планов ([[06-Консилиум-и-конфликты/Реестр-конфликтов-и-решений|CONF-01]]). Архитектура `sf v3.0` опирается на готовые специализированные инструменты, разделяя 4 контура: **(1) Live-навигация по коду** (`colbymchenry/codegraph`, `codebase-memory-mcp`, `Serena`), **(2) Граф документации и контрактов** (`Graphify`), **(3) Периодический валидированный batch-аудит и SAST/архитектурные сканеры** (`Green Olive CodePrizm`, `CodeQL`, `Semgrep`, `Gitleaks`, `ArchUnit/dependency-cruiser/import-linter`) и **(4) Обратимое сжатие контекста и кэш-выравнивание** (`RTK`, `Headroom CCR`).

## 2. Верифицированные команды подключения `Graphify` и `Headroom`

```bash
# 1. Graphify (ВАЖНО: пакет в PyPI называется graphifyy с двумя 'y', команда CLI — graphify)
uv tool install graphifyy
graphify claude install      # CLAUDE.md + PreToolUse hook для Claude Code
graphify opencode install    # AGENTS.md + плагин tool.execute.before для OpenCode
graphify codex install       # AGENTS.md для OpenAI Codex
graphify hook install        # авто-обновление + git merge-driver для бесконфликтного слияния graph.json!

# Запросы к графу контрактов с жёстким бюджетом токенов и трассировкой пути:
graphify query "какие правила закрытия задачи зависят от approvals?" --budget 1500 --dfs --graph graphify-out/graph.json
graphify path "FLOW-create-task" "ENT-task-record"
graphify explain "validate_document_body"
# Опционально поднять локальный MCP-сервер только для субагента planner/verifier:
python -m graphify.serve --graph graphify-out/graph.json

# 2. Headroom (обратимое CCR-сжатие + защита префикса KV-кэша CacheAligner)
uv tool install --python 3.13 "headroom-ai[all]"
headroom wrap claude         # или: headroom wrap opencode | codex | aider | cursor
headroom doctor && headroom perf
```

## 3. Защита от «Тихого налога схем MCP» и нормализация результатов аудита (`Finding Schema`)

1. **Правило `0` графовых MCP у слабой модели (`PROB-31`, `R20`):** глобальное подключение 30–50 тулов сжигает `9K–16K` ток./шаг и рушит точность малых моделей ([`arXiv:2610.33958`](https://arxiv.org/pdf/2610.33958)). Поэтому `implementer` работает вообще без графовых MCP (получая `envelope ≤2k` от `locator` по лестнице `codegraph_explore → точечные строки Read → ограниченный grep`), а графовые MCP скоупятся строго внутрь `locator` и `verifier`.
2. **Единый нормализованный формат находок сканеров и аудиторов** (синтез с [Инструменты аудита для software factory.md](<../../machinedocs-encyclopedia/Практики/Инструменты аудита для software factory.md>) и [Архитектура агентной software factory.md](<../../machinedocs-encyclopedia/Практики/Архитектура агентной software factory.md>)):
   - Для детерминированных проверок слоёв, секретов и уязвимостей до человека и до агента-фиксера используются штатные CLI-инструменты с выводом SARIF/JSON: `Gitleaks`, `Semgrep`, `CodeQL`, `OSV-Scanner`, архитектурные тесты слоёв (`ArchUnit` для JVM, `NetArchTest` для C#, `dependency-cruiser` для TS/JS, `import-linter`/`deptry` для Python), property-based тесты (`Hypothesis`, `jqwik`, `QuickCheck`) и микробенчмарки (`pyperf`, `k6` с фиксацией `base vs candidate`).
   - Любая находка (`CodePrizm`, `Semgrep`, `CodeQL` или `verifier`) перед постановкой задачи на починку нормализуется в строгую запись с отделением новых дефектов от исторического долга (`baseline_status: "new" | "existing"` — правило brownfield *«не ухудшать baseline + отдельный бэклог техдолга»*):
   ```json
   {
     "id": "AUD-2026-0014",
     "tool": "codeprizm | semgrep | codeql | verifier",
     "rule_id": "ARCH.LAYER_CYCLE",
     "fingerprint": "sha256:...",
     "severity": "critical | high | medium | low",
     "confidence": "high | medium | low",
     "commit": "f8cb406",
     "baseline_status": "new",
     "location": { "path": "doc/tools/arch/body_validation.py", "symbol": "validate_document_body", "lines": [41, 88] },
     "evidence": "returns [] because properties key is skipped",
     "fix_scope": ["doc/tools/arch/body_validation.py", "doc/tests/test_doc_contracts.py"],
     "needs_human": false
   }
   ```
