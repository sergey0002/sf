# 📖 Справочник артефактов, команд, схем и кодов возврата `sf v3.0`

> [!abstract] Кратко
> Быстрый нормативный справочник (по единому стандарту со `Справочник форматов.md` и `Справочник сущностей.md` соседних энциклопедий `data/`) по всем машиночитаемым файлам, производным представлениям, кодам выхода `CliEnvelope`, состояниям свежести `Validity L1` и точкам стыковки с энциклопедиями `data/`.

## 1. Полная карта артефактов и JSON-схем `sf v3.0` (`Канон` vs `Generated View` vs `Кэш`)

| Артефакт | Путь в репозитории | Режим (`SSOT` / `Generated` / `Cache`) | Схема / Валидатор | Назначение |
|---|---|---|---|---|
| **Карточка замысла задачи** | `doc/tasks/<KEY>/task.json` | **SSOT в Git** (неизменяемый `intent` после `init`, меняется только через `revise`) | `schema.py` + `validation.py` (`intent_digest`) | Цель, `AC`, `unchanged_behavior`, `flow_refs`, `risk`, `approvals`, `owner` |
| **Проекция состояния задачи** | `doc/tasks/<KEY>/state.json` | **Generated в Git** (восстанавливается из `events.jsonl` через `replay`) | `task-state-1` (`task_record.py`) | Текущая фаза, ревизия, статус подзадач и активного флоу |
| **Журнал событий задачи** | `doc/tasks/<KEY>/events.jsonl` | **Append-only SSOT в Git** | `task_record.py` (`event_id`, `prev_digest`) | Идемпотентная цепочка переходов фаз, решений и сбоев (`Cold Resume`) |
| **Пакет исполнения стадии** | `doc/tasks/<KEY>/stageN/workpack.json` | **SSOT стадии в Git** (рендерит `stageN/plan.md`) | `workpack.schema.json` (`F1`) | `allowed_edit_spans`, `input_leases`, `oracles[]` со строгим `"passes": false` |
| **Дельта архитектурного флоу** | `doc/tasks/<KEY>/stageN/flow-delta.json` | **SSOT стадии в Git** (вливается `delta apply`) | `flow-delta.schema.json` (`F2`) | Операции `add_branch / modify_branch / remove_branch / supersede_branch / remap_code` |
| **Доказательство приёмки** | `doc/tasks/<KEY>/stageN/verification.json` | **SSOT приёмки в Git** | `verification.schema.json` `v1.0` (`F0`) | `checked_revision`, `red_exit_code != 0`, `exit_code == 0`, `result ∈ {pass, fail, not_run}`, `snapshot_sha256` |
| **Отчёт независимого ревьюера** | `doc/tasks/<KEY>/stageN/verifier-report.json` | **SSOT ревью в Git** | `verifier-report.schema.json` (`F2`) | Пофункциональные ответы на 4 вопроса Winninger с другой модели (`model_verifier != model_implementer`) |
| **Канонический архитектурный флоу** | `doc/architecture/domains/<d>/flows/<slug>.flow.json` | **SSOT контракта в Git** | `arch-flow.schema.json` (`F2`) | Таблицы решений DMN (`UNIQUE`/`COLLECT`), состояния `lifecycle`, `effects.atomicity`, `refs` |
| **Витрина архитектурного флоу** | `doc/architecture/domains/<d>/flows/<slug>.md` | **Generated в Git** (`arch docs flow build`) | `arch docs flow check` | Читаемый Markdown с таблицами решений и диаграммами `Mermaid` |
| **Графовый индекс всех флоу** | `doc/architecture/flows.index.json` | **Generated в Git** (`arch docs flow build`) | `arch docs flow check` | Плоский реестр `FLOW-ID#branch-id` и обратный граф `referenced_by` по 8 осям |
| **Манифест внешних провайдеров** | `.sf/providers.yaml` | **SSOT конфига в Git** | Валидатор среды (`F00/F3`) | Пиннинг MIT-графов (`codegraph`, `cbmemory`, `graphify`, `serena`), компрессоров (`rtk`, `headroom`) и дифф-мутаторов |
| **Локальный индекс замысла и аренд** | `.sf/intent.sqlite` | **Gitignored Cache** (пересобирается за мс) | `WAL + FTS5` (`F2`) | Таблицы `intent_nodes`, `symbol_bindings` и `task_leases` (`read_input / write_exclusive`) |
| **Переносимый снимок графа кода** | `.codebase-memory/graph.db.zst` | **Shared Artifact** (распаковывается в `worktree`) | `codebase-memory-mcp` | Мгновенный старт параллельных `worktree`-волн без повторного парсинга `3 500+` файлов |

## 2. Семантика кодов возврата `CliEnvelope` ([doc/tools/arch/cli/errors.py](<../../doc/tools/arch/cli/errors.py>))

Все команды `arch` при `--json` обязаны возвращать единый JSON-конверт `{ok, code, data, errors: [{code, message, field, suggestion, exit_code}], hints}` (включая ветки раннего отказа — фикс бага `UI-0011`!):

| Код выхода | Константа | Строгое значение для агента и оркестратора |
|---:|---|---|
| **`0`** | `EXIT_OK` | Успех проверки или атомарной операции |
| **`1`** | `EXIT_ERROR` | Бизнес/контрактный отказ: нарушение JSON Schema, дыра/пересечение в DMN, `APPROVAL_REQUIRED`, дрейф generated-файла, падение оракула или выживший мутант |
| **`2`** | `EXIT_ARGS` | Неверный синтаксис аргументов CLI или идентификатора (`UI-NNNN`, `FLOW-*#branch`) |
| **`5`** | `EXIT_CONFLICT` | Конфликт оптимистической блокировки (`expected_revision`, `base_sha256` при `delta apply`, пересечение `write_exclusive` lease) |
| **`10`** | `EXIT_AUTH` | Нарушение границ безопасности: запись вне `allowed_paths` / `paths.yaml` или попытка кодера изменить `RO Trust Zone` (`tests/**`) |
| **`20`** | `EXIT_NOT_FOUND` | Запрошенный документ, задача, сессия или ветка флоу не существуют |

## 3. Пятизначная шкала свежести входов `Validity L1` ([taskcontrol.md](<../../taskcontrol.md>))

| Статус `validity` | Условие | Разрешён ли старт `implementer`? |
|---|---|---|
| `current` | Все входные `DOC-ID`, `FLOW-ID#branch` и `symbol_uri` совпадают по `base_sha256` с текущим `HEAD`, конфликтов с активными задачами нет | **Да** |
| `stale` | Один из входных контрактов или символов изменился после фиксации снимка задачи | **Нет** — требуется `task audit` и пересборка `workpack.json` |
| `conflicted` | Пересечение по `scope.out` или `write_exclusive` lease с другой активной задачей (пример: `UI-0030` vs `UI-0029`) | **Нет** — развести по волнам `waves` или уточнить границы |
| `superseded` | Задача или целевая ветка флоу заменена новым решением (`superseded_by`) | **Нет** — закрыть или перенаправить по `superseded_branches` |
| `unknown` | Снимок входов ещё не снят (`snapshot` отсутствует) | **Нет (`unknown ≠ current`!)** — сначала выполнить `arch task snapshot` |
