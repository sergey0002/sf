# 📖 Справочник форматов описания CLI

Единый каталог форматов описания CLI для моделей: файл, стандарт, формат,
назначение и ссылка на полную страницу энциклопедии. См. [[Главная]] и [[Глоссарий]].

## Карта форматов

```mermaid
flowchart TB
    subgraph PROC["Процедурные (как делать)"]
        SK[[Agent Skills (SKILL.md)]]; AG[[Инструкционные файлы]]
    end
    subgraph SELF["Самоописывающие (что умеет)"]
        HELP[[Help-текст CLI]]; MAN[[Man Pages]]; JSON[[JSON Schema и Self-Description]]; COMP[[Shell Completions]]
    end
    subgraph TYPED["Типизированные (схемы)"]
        MCP[[MCP Tools]]; OAS[OpenAPI]
    end
    SK --> SCR[[Scripts]] & REF[[References]] & AST[[Assets]]
    DES[[Agent-Friendly CLI Design]] -.-> HELP & JSON
```

## 1. Форматы описания CLI

| Формат | Файл / механизм | Стандарт | Назначение | Страница |
|---|---|---|---|---|
| Agent Skills | `SKILL.md` в папке скилла | agentskills.io (открытый) | Процедура для модели: когда и как | [[Agent Skills (SKILL.md)]] |
| Frontmatter | YAML-шапка SKILL.md | Спецификация Skills | Метаданные и триггер | [[Frontmatter]] |
| Progressive Disclosure | 3 уровня загрузки | Anthropic | Экономия контекста | [[Progressive Disclosure]] |
| Инструкционные файлы | `AGENTS.md`, `CLAUDE.md` | Стандарт 2026 | Инструкции проекта | [[Инструкционные файлы]] |
| Help-текст | `--help` | Unix-конвенция | Самодокументирование | [[Help-текст CLI]] |
| Man Pages | `man <cmd>` | Unix (troff) | Полное руководство | [[Man Pages]] |
| JSON Schema / Self-Description | `--describe`, `--help --json` | Agent-Friendly CLI Spec | Машиночитаемое описание | [[JSON Schema и Self-Description]] |
| MCP Tools | JSON-RPC сервер | Model Context Protocol | Типизированные инструменты | [[MCP Tools]] |
| Shell Completions | completion-скрипты | Bash/Zsh/Fish | Автодополнение | [[Shell Completions]] |

## 2. Анатомия скилла

| Компонент | Роль | Загрузка | Страница |
|---|---|---|---|

| `assets/` | Шаблоны, файлы вывода | Не загружается | [[Assets]] |
