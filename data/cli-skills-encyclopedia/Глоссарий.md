# 📚 Глоссарий терминов CLI и Skills

> Полный каталог форматов — [[Справочник форматов]].

## A–D

- **Agent Skills** — открытый стандарт скиллов (agentskills.io). См. [[Agent Skills (SKILL.md)]].
- **AGENTS.md / CLAUDE.md** — файлы инструкций проекта. См. [[Инструкционные файлы]].
- **allowed-tools** — экспериментальное поле frontmatter: предодобренные инструменты.
- **Assets** — шаблоны и ресурсы скилла, не загружаемые в контекст. См. [[Assets]].
- **BPMN** — не относится к CLI; см. энциклопедию SDD.
- **Compatibility** — поле frontmatter: требования окружения (≤500 символов).
- **Composability** — компонуемость CLI: цепочки команд. См. [[Работа агентов с CLI]].
- **Dry-run** — предпросмотр без исполнения. См. [[Agent-Friendly CLI Design]].
- **Envelope** — единый формат JSON-ответа CLI. См. [[JSON Schema и Self-Description]].

## E–M

- **Exit Codes** — коды возврата как control flow агента. См. [[Agent-Friendly CLI Design]].
- **Freedom Levels** — уровни свободы инструкций скилла: low/medium/high.
- **Frontmatter** — YAML-шапка SKILL.md (name, description). См. [[Frontmatter]].
- **Help-текст** — самодокументирующийся --help. См. [[Help-текст CLI]].
- **Idempotency** — идемпотентность операций CLI. См. [[Agent-Friendly CLI Design]].
- **Man Pages** — страницы руководства Unix. См. [[Man Pages]].
- **MCP** — Model Context Protocol: JSON-RPC инструменты. См. [[MCP Tools]].
- **Metadata** — произвольные key-value в frontmatter.
- **NDJSON/JSONL** — потоковый JSON, объект на строку.

## N–S

- **Progressive Disclosure** — трёхуровневая загрузка скилла. См. [[Progressive Disclosure]].
- **References** — документация скилла, загружаемая по требованию. См. [[References]].
- **Scripts** — исполняемый код скилла, не загружаемый в контекст. См. [[Scripts]].
- **Self-Description** — --describe/--help --json: CLI описывает себя машиной. См. [[JSON Schema и Self-Description]].
- **Shell Completions** — автодополнение команд. См. [[Shell Completions]].
- **SKILL.md** — главный файл скилла. См. [[Agent Skills (SKILL.md)]].
- **skills-ref** — референсная библиотека валидации скиллов.
- **skills.sh** — каталог скиллов (Vercel).

## T–Z

- **TTY Detection** — определение терминала: rich vs clean output.
- **Trigger** — описание скилла как механизм активации.
