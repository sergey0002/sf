# Политика выделения и реестра номеров задач

## Политика (из корневого манифеста)

- У каждой задачи ровно четыре десятичные цифры (`0000`–`9999`) как `task_number`.
- `task_key` детерминирован:
  - Jira: только чистое число (`1234`), без префикса.
  - Ввод пользователя (`source.type: ui`): `UI-` + число (`UI-1234`).
  - Каждый другой источник: явный зарегистрированный/настроенный префикс + число (`GH-1234`).
- CLI выводит/валидирует ключи, но **никогда не выделяет** номера.
- Выделение номеров, глобальная уникальность и миграция нерешены; дублирующие ключи должны останавливаться, а не перезаписываться.

## Текущие назначения

| task_key | источник | task_number | статус | примечания |
|----------|----------|-------------|--------|----------|
| UI-0001 | ui | 0001 | scaffold | Локальная фикстура; никакого глобального резервирования не подразумевается |

## Правило остановки

Перед присвоением нового номера подтвердите тип источника и префикс с владельцем. Не выдумывайте и не угадывайте префикс. Если источник не Jira, не UI и не имеет настроенного префикса, остановитесь и спросите.
