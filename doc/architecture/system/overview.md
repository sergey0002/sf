# Фабрика программного обеспечения одного агента

## Назначение

Дизайн программной фабрики, ориентированной на агента и локальной к репозиторию, которая превращает запрос пользователя в валидированный канонический `task.json`, поддерживает ограниченную работу задачи и сохраняет доказательства верификации/ревью.

## Граница области

- Текущее ядро — один агент. Мультиагентная оркестрация не включена.
- Приём может исходить из трекера, чата или ручного запроса; интеграции провайдеров нерешены.
- Детерминированные операции принадлежат небольшому CLI. Семантическая интерпретация, релевантность документов, планирование и архитектурное суждение остаются обязанностями агента.
- Одобрение человека и доказательства верификации являются первоклассными ограничениями.
- Будущая отдельная программа сканирования документации кода с собственной очередью/возможными суб-агентами может создавать предложения Markdown. Это не это ядро, и её внутренний формат очереди/вывода не является каноническим.
