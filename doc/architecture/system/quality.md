# Атрибуты качества

| Атрибут | Сценарий / предполагаемая реакция | Открытая мера/решение |
|---------|----------------------------------|----------------------|
| Трассируемость | Учитывая задачу/результат, рецензент может проследить исходный запрос, снапшот задачи, diff, точные проверки и одобрение | Схема доказательств, хранение и ссылки |
| Безопасность | Учитывая недоверенный ID/контент или грязную/неизвестную цель, операции завершаются неудачей до мутации пути/репо | Модель угроз, разрешённые команды, механизм изоляции |
| Рецензируемость | Учитывая предложенное изменение, рецензент видит фокусированный diff, допущения, пробелы и выводы верификации | Роли одобрения и требуемые шлюзы |
| Эффективность извлечения | Учитывая задачу, агент начинает с индекса и загружает релевантные документы только | Набор базы/оценки и метрики стоимости/качества |
| Воспроизводимость | Учитывая записанную команду верификации и состояние кода, авторизованный исполнитель может повторить её | Захват среды и цель воспроизводимости |
| Поддерживаемость | Учитывая новые знания домена, автор может добавлять/обновлять краткий связанный Markdown без специального инструмента сканера | Политика владения и свежести |
| Переносимость провайдера | Учитывая изменение провайдера модели, конфигурацию маршрутизации можно изменить без переписывания знаний домена | Совместимость API и политика данных |

Количественные SLO, цели производительности или эмпирические доказательства не установлены.
