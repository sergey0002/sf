# Логические компоненты

| Компонент | Ответственность | Не должен |
|-----------|-----------------|------------|
| Адаптеры трекера/чата | Извлекать авторизованные явные поля источника, сохранять идентичность/происхождение | Семантически классифицировать, выбирать релевантные документы, выводить приёмку |
| Task CLI | Валидация схемы/пути, нормализация ключа задачи, выделение UI-номера из CLI-реестра, детерминированные операции рабочего пространства | Принимать решения, требующие суждения, скрывать политику или позволять агенту вести реестр вручную |
| Скиллы агентов | Интерпретировать запрос, задавать вопросы, извлекать релевантные документы, планировать и communicating | Заявлять о проверках/одобрении без доказательств |
| Знания архитектуры | Канонический Markdown, схемы, ссылки, сгенерированный индекс и происхождение | Зависеть от приватного формата вывода сканера |
| CLI/конфигурация модели | Настраивать поддерживаемые модели/конечные точки провайдеров | Принуждать к ядру с múltiples агентов |
| Рабочее пространство выполнения | Изолированная ветка/рабочее дерево задачи с контролируемым доступом к файловой системе/процессам | Push/deploy без явного одобрения |
| Верификация/доказательства | Выполнять настроенные проверки и сохранять фактические результаты | Превращать самоотчёт в независимый оракул |
| Одобрение человеком | Ревью diff, разрешение нерешённой области, авторизация шлюзов | Выводиться из успеха агента |

## Статус

Только логические границы; не выбрана топология среды выполнения/пакета/развёртывания.
