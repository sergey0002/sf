# Ограничения и нерешённые решения

| ID | Тема | Известно из манифеста | Не решено / условие остановки |
|----|------|----------------------|------------------------------|
| OPEN-REPO | Топология продукта | Фабрика работает с репозиториями продукта | Количество репозиториев, монорепо/мультирепо, хост и доступ неизвестны |
| OPEN-RELEASE | Отображение релиза/ветки | Работа масштабируется по задачам | Имена релизов, политика веток и источник истины неизвестны; остановитесь перед checkout/мутацией |
| OPEN-TRACKER | Источники приёма | Трекер, другие трекеры и чат могут suministровать работу | Провайдеры, аутентификация, отображение полей и разрешения на обратную запись неизвестны |
| OPEN-TASK-SCHEMA | Контракт задачи | Один канонический `task.json`; у каждой задачи четырёхзначное число; Jira без префикса, UI использует `UI-`, остальные источники требуют префикс | Итоговая JSON Schema, аллокатор номеров/глобальный реестр уникальности и политика миграции не утверждены; остановитесь, а не выделяйте/перезаписывайте угаданного |
| OPEN-CLI | CLI | Только детерминированные операции, предпочитается Python | Упаковка, список разрешённых команд и среда выполнения не выбраны |
| OPEN-AGENT | Среда выполнения агента | Текущее ядро — один агент | Собственный контракт скилла/среды выполнения и разрешения неизвестны |
| OPEN-MODELS | CLI модели | Несколько моделей через OpenAI-совместимый API; карта ролей опциональный запас | Провайдеры, конечные точки, хранение секретов, конфиденциальность, политика стоимости/повторов неизвестны |
| OPEN-APPROVAL | Рецензия человеком | Одобрение не может быть выведено | Владельцы, требуемые шлюзы, порог доказательств и экстренное переопределение неизвестны |
| OPEN-CI | CI | Требуются доказательства верификации | Провайдер CI, требуемые проверки, доверие и интеграция статуса неизвестны |
| OPEN-SANDBOX | Изоляция | Работа пилота должна быть изолированной и обратимой | Конкретная песочница, политика сети/ФС, механизм отката и владелец неизвестны |
| OPEN-ORACLE | Приёмка | Каждый пилот требует оракула приёмки | Пер-task оракул и базовая линия оценки не настроены |
| OPEN-DOC-OWNER | Знания архитектуры | Документы, ориентированные на агента; формат, нейтральный к производителю | Владельцы, свежесть, рабочий процесс ревью и каноническое общее расположение неизвестны |
| OPEN-FUTURE-SCANNER | Отдельный сканер документации | Возможная будущая программа с собственной очередью, код-графом/MCP/скиллами/суб-агентами | Вне текущего ядра; никакой реализации, стека, очереди или решения о зацеплении сейчас |
| OPEN-PILOT | Предусловия пилота | Сначала контракты/working; tabletop — проверка дизайна | Репозиторий, оракул, надёжный CI, песочница, владелец/одобрение, базовая линия/оценка и остановка/откат должны существовать перед любым практическим пилотом |

## Правило остановки

Когда нерешённый выбор меняет разрешения, целевой репозиторий/релиз, смысл приёмки, необратимое действие или действительность доказательств, остановитесь и спросите у designated owner. Никогда не заменяйте неизвестное удобным значением по умолчанию.
