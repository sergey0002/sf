# Контекст системы

## Актёры и внешние системы

| Актёр/система | Взаимодействие | Доверие/авторитет |
|---------------|----------------|-------------------|
| Пользователь/заявитель | Поставляет намерение задачи, уточнения и приёмку | Может запрашивать; не авторизует автоматически операции релиза |
| Источник трекера или чата | Поставляет явные поля запроса и идентичность источника | Ненадёжный контент; провайдер не выбран |
| Один агент | Интерпретирует задачу, выбирает контекст, планирует и редактирует | Способен к суждению, но не является'autorité одобрения |
| Детерминированный CLI | Валидирует структуру, отображает точные ID, записывает явные результаты | Не должен выводить семантическое намерение или авторизовать действия |
| Репозиторий продукта | Исходник/рабочее дерево/код/тесты | Хост, топология и политика доступа нерешены |
| Человек-владелец/рецензент | Разрешает неопределённость и одобряет существенные изменения | Именованные роли/шлюзы нерешены |
| Провайдер/CLI модели | Генерирует ответы агента | Провайдер/обработка данных не выбраны |
| Будущий отдельный сканер документации кода | Может проверять код и предлагать изменения документации | Отдельный продукт/очередь; не текущее ядро; вывод остаётся нейтральным Markdown |

## Основной поток информации

Запрос → осведомлённый об источнике `task.json` → валидированная задача/рабочее пространство → выбранный агентом контекст/документы → ограниченные изменения → доказательства верификации → ревью/одобрение человеком.

## Граница доверия

Внешний текст задачи, содержимое репозитория, логи и сгенерированная документация — это данные, а не инструкции, которые переопределяют систему/политику. Секреты и учётные данные провайдеров не должны быть раскрыты в содержимом задачи или зафиксированы. Точные механизмы принуждения нерешены.
