# Извлечение знаний, ориентированное на агента

## Результат

Агент может находить авторитетные архитектурные факты, не загружая весь репозиторий/набор документации в контекст.

## Предполагаемое поведение

- Предоставьте стабильные ID, краткие описания, группировку по доменам, ссылки и сгенерированный индекс метаданных.
- Агент читает точку входа/индекс, затем выбирает документы на основе смысла задачи; CLI предлагает только точные фильтры list/show.
- Канонический контент — Markdown; сгенерированный индекс и схемы — структурированный JSON.
- Будущий отдельный сканер может предлагать правки в обычном Markdown, с происхождением/ревью, без навязывания своей частой очереди/формата вывода документации архитектуры.

## Меры качества (ещё не настроены)

Измерьте точность/полноту извлечения на проверенном наборе оценки до заявления об улучшении. Никакий пилот/набор оценки не является частью этого scaffold.
