# Знания проекта

## Назначение и граница

Храните канонические знания, пригодные для агента, и контекст репозитория отдельно от ввода задачи, доказательств выполнения и реализации инструмента/среды выполнения. Архитектура — нейтральный к производителю Markdown с проверенным frontmatter и сгенерированным индексом.

## Принадлежит

- карты, ориентированные на агента, страницы доменов, записи возможностей/потоков/сущностей/решений и ссылки на источники;
- дисциплину извлечения: ориентация через индекс, затем селективная загрузка по смыслу и расширение, управляемое доказательствами;
- происхождение, статус ревью, политика свежести/владения как будущие контракты.

Рабочий маршрут постановки и исполнения описан в [architecture-read](../../../skills/architecture-read/SKILL.md). Извлечение начинается с ID и ссылок карточки, при пробеле — с фильтра домена и типа. В плане сохраняют точный раздел и влияние на сценарий приёмки. [Index-First в data](<../../../../data/machinedocs-encyclopedia/Архитектура/Index-First подход.md>)

## Не принадлежит

- специальный формат, привязанный к будущему сканеру; выбор кода графа/MCP производителя вне текущей области;
- семантическое совпадение CLI или оценку истинности контента.

## Текущее ограничение

Модель владельца, авторитетные расположения источников, проверки свежести, трассируемость кода-документов и шлюзы CI не решены в корневом манифесте.
