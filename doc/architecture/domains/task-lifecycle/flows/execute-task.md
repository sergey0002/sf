# Выполнение одной задачи

## Триггер и актёры

`go to task <task_key>`; CLI, скиллы, один агент, рабочее дерево/репозиторий продукта, система тестирования/CI и ревьюер/владелец.

## Предусловия

Валидный `task.json`, настроенный репозиторий и отображение источника/релиза, разрешённая песочница и оракул приёмки. Если требуемое отображение или решение нерешено, остановитесь/спросите; никакие значения не принимаются в этом примере.

## Основной путь

| Path ID | Шаг | Действие | Исход / доказательство |
|---|---|---|---|
| FLOW-execute-task-P1 | Прочитать задачу | CLI валидирует явный ввод задачи и проверяет состояние репозитория/рабочего дерева | Базовые ссылки и безопасное состояние рабочего пространства |
| FLOW-execute-task-P2 | Инспектировать/контекст | Скилл агента извлекает только релевантный код/документы/тесты, спрашивает о блокерах | Контекст со ссылками на доказательства и нерешённые вопросы |
| FLOW-execute-task-P3 | Планировать | Агент создаёт ограниченный план этапа; дельта архитектуры только если значима | Проверяемый план/дельта |
| FLOW-execute-task-P4 | Реализовать | Один агент изменяет код и исполняемые тесты в изолированной ветке задачи | Код/diff тестов |
| FLOW-execute-task-P5 | Верифицировать | CLI запускает только явно разрешённые команды и захватывает коды выхода/ссылки на выводы; CI может предоставить независимые доказательства | Запись верификации, привязанная к проверенному состоянию |
| FLOW-execute-task-P6 | Ревью/продвинуть | Человек ревьюит семантическую область, код/diff документов и доказательства; человек слияет/релизит | Одобренный исход или запрошен новый этап |

## Условия остановки

Грязное/неожиданное рабочее дерево, нерешённое отображение релиза/ветки, отсутствующий оракул приёмки, отказ в разрешении, неопределённость области requiring owner, или неудача требуемых проверок. Точная политика требует контрактов репозитория/CI.

## Не цели

Нет автоматического push/merge/deploy, нет параллельного назначения агентов, нет скрытого семантического выбора архитектуры, нет утверждения, что зелёные тесты доказывают несказанное намерение пользователя.
