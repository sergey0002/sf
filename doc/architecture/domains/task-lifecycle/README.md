# Жизненный цикл задачи

## Назначение и граница

Сохраняйте идентичность и историю от нормализованного ввода задачи через ограниченные этапы и доказательства верификации. Эта страница описывает предполагаемые концепции, а не реализованный конечный автомат.

## Принадлежит

- неизменяемый исходный ввод задачи после начала выполнения;
- идентичность записи задачи/этапа, переходы состояний и происхождение (точные схемы не решены);
- план/результаты этапа и ссылки на доказательства;
- безопасное возобновление из проверенного состояния задачи/рабочего дерева.

## Инварианты

- Один канонический ввод задачи; записи этапов дополняют, никогда не заменяют его.
- Результат не является пройденным без захваченных доказательств верификации.
- Проверяйте целевую ветку и релиз, когда они нужны для конкретного действия. Сохраняйте чужие изменения и согласуйте пересекающиеся правки.
