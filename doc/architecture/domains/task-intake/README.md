# Приём задач

## Назначение и граница

Нормализуйте запросы, arriving из трекера, чата или ручного ввода, в единственный канонический ввод задачи, `task.json`. Адаптеры поставщика/транспорта извлекают явные поля и сохраняют происхождение; агент выполняет семантическую интерпретацию и уточнение.

## Принадлежит

- сохранение идентичности/происхождения источника и детерминированные контракты нормализации;
- схема/управление версиями `task.json`, безопасность ключа задачи и создание рабочего пространства задачи (детали не решены);
- различие между детерминированной работой адаптера/CLI и суждением агента.

## Не принадлежит

- семантическая классификация требований CLI;
- выполнение кода продукта, вердикт теста или одобрение релиза;
- отдельно authored task.md;
- любой конкретный провайдер трекера/чата, не выбранный в корневом манифесте.

## Инварианты / нерешено

`task.json` — единственный канонический ввод задачи. Каждая задача имеет десятичное число задачи из четырёх цифр. Ключи Jira не имеют префикса; ключи UI (ввод пользователя) используют `UI-`; все остальные источники требуют явного префикса. CLI ведёт JSON-реестр; для `source: ui` команда `task new` выделяет следующий свободный номер, создаёт задачу и добавляет запись. Глобальная уникальность между источниками и точные контракты адаптеров источников остаются нерешёнными.
