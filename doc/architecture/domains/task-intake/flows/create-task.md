# Поток создания задачи

## Назначение и возможность

Превратить один внешний/ручной запрос в рабочее пространство задачи, осведомленное об источнике, с каноническим `task.json`.

## Триггер, участники и задействованные системы

Пользователь, источник трекера или чата, адаптер/CLI, скилл агента и рабочее пространство задачи. Точные продукты/протоколы не указаны.

## Предусловия и авторизация

Существует настроенный источник или запрос в ручном чате. Разрешения на чтение трекера и пути рабочего пространства — явная конфигурация проекта; не определены в этом примере.

## Основные и альтернативные пути

| Path ID | Охрана/событие | Актёр | Действие/побочный эффект | Исход | Отказ/следующий шаг |
|---|---|---|---|---|---|
| FLOW-create-task-P1 | Запрошена задача трекера | Адаптер CLI | Извлеките точные поля/комментарии/вложения; сохраните ссылки на ревизию/снапшот источника | Доступны необработанные доказательства источника | Отказ адаптера/API сообщается; задача не создаётся молча |
| FLOW-create-task-P2 | Запрос человека в чате | Скилл агента | Интерпретируйте намерение, идентифицируйте блокирующую неопределённость и задайте вопросы | Уточнённые семантические поля | Ждите ответов при блокировке; не позволяйте CLI делать выводы |
| FLOW-create-task-P3 | Достаточно известных данных для создания ввода | Скилл агента | Создайте осведомлённый об источнике `task.json` | Кандидат на канонический ввод | Неизвестные поля остаются явными/неустановленными только там, где разрешено |
| FLOW-create-task-P4 | JSON предоставлен | CLI | Валидируйте схему/пути/ID и создайте безопасное рабочее пространство/шаблоны | Рабочее пространство задачи создано | Ошибка схемы или идентичности останавливает; никакой обратной записи в трекер по умолчанию |

## Данные и ссылки

Каждый кандидат на задачу должен иметь ровно четырёхзначное `task_number`; детерминированный ключ — чистый для Jira, с префиксом `UI-` для ввода пользователя/UI, и явно с префиксом для любого другого источника. CLI только валидирует/выводит: он не выделяет числа. Глобальное выделение чисел/уникальность и итоговая схема не стандартизированы еще. `task.json` — единственный канонический нормализованный ввод задачи; необработанный снапшот источника и вложения остаются отдельно идентифицируемыми доказательствами.

## Явные исключения

Нет автоматических обновлений трекера, семантической классификации в CLI, вывода полноты задачи или выбора релиза.
