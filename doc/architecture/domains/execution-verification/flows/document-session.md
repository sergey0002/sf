# Поток документирования сессии

## Триггер и область

Пользователь явно вызывает скилл `задокументируй` в любой момент. Скилл захватывает подтверждённые факты/решения/доказательства, а не дамп транскрипта.

## Пути

| Path ID | Условие | Действие | Результат | Ревью/доказательство |
|---|---|---|---|---|
| FLOW-document-session-P1 | Активная задача/этап существует | Классифицируйте факты текущей сессии vs гипотезы; обновите соответствующий артефакт задачи/этапа и подготовьте дельту архитектуры, если канонические знания изменились | Запись этапа со ссылками на источник; исходный `task.json` без изменений | Ревью/одобрение владельцем перед каноническим обновлением по мере необходимости |
| FLOW-document-session-P2 | Нет активной задачи | Обновляйте только чётко релевантные документы архитектуры; не создавайте задачу задним числом | Только предложение/изменение канонического документа | Структурные проверки и обычное ревью |
| FLOW-document-session-P3 | Смысл/доказательства неясны | Спросите или отметьте нерешённым; не заявляйте об удачной реализации/пройденных тестах | Никакого ложного факта не записано | Продолжайте после уточнения |

## Инварианты

Сохраняйте ссылки на источники; не создавайте факты из намерения пользователя; различайте реализованное поведение, подтверждённое решение, предложение и гипотезу; запускайте проверки CLI архитектуры после правок. Точная интеграция инструментов скилла не выбрана.
