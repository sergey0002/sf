# Выполнение и верификация одним агентом

## Назначение

Выполнять задачу последовательно в ограниченном рабочем пространстве, сохраняя независимую верификацию и границы одобрения человеком.

## Требования

### Требование: ядро работает одним агентом

Фабрика ДОЛЖНА использовать одного агента для семантического планирования и рабочего процесса реализации текущего MVP.

#### Сценарий: задача выполняется

- **КОГДА** задача входит в реализацию
- **ТОГДА** один агент выполняет ограниченный рабочий процесс; мультиагентное назначение не требуется

### Требование: CLI остаётся детерминированным

CLI ДОЛЖЕН выполнять только повторяемые операции над явными структурированными входами и НЕ ДОЛЖЕН решать семантическое намерение, релевантность или архитектурное влияние.

#### Сценарий: архитектурный документ может быть затронут

- **КОГДА** доступен контекст задачи и кода
- **ТОГДА** агент/скилл выбирает релевантные документы, а CLI валидирует явные ссылки и структуру документа

### Требование: доказательства верификации привязаны к состоянию

Фабрика ДОЛЖНА ассоциировать захваченные результаты тестов/доказательств с точным состоянием кода, которое было проверено.

#### Сценарий: запускается тестовая команда

- **КОГДА** CLI записывает результат
- **ТОГДА** записываются команда, код выхода, ссылка на вывод и состояние проверенного коммита/рабочего дерева

### Требование: защищенное продвижение не автоматическое

Фабрика НЕ ДОЛЖНА по умолчанию выполнять push, merge или deploy; требуется одобрение человека в соответствии с будущей политикой.

#### Сценарий: проверки проходят

- **КОГДА** агент сообщает о завершении
- **ТОГДА** отчёт является доказательством для ревью, а не автоматическим разрешением на слияние или развёртывание
