# Настраиваемая CLI модели

## Результат

Фабрика может использовать настраиваемые реализации CLI модели и несколько моделей через OpenAI-совместимые API без привязки знаний архитектуры к поставщику.

## Опциональный запасной вариант

Отображение ролей на модели может использоваться, когда собственная поддержка суб-агентов слабая. Роли настраивают выбор модели только; это само по себе не создаёт оркестрацию или параллельных работников.

## Нерешённые требования

Точная совместимость, секреты, разрешения модели, конфиденциальность, бюджет, повторные попытки, наблюдаемость и семантика запасного варианта должны быть решены перед развёртыванием.
