# Резервная рольозависимая CLI модели

## Назначение

Позволить скиллу агента, при необходимости, делать явную консультацию без сохранения состояния, используя настроенное отображение `роль → модель` через OpenAI-совместимый API.

## Требования

### Требование: маршрутизация ролей — явная конфигурация

CLI модели ДОЛЖНА маршрутизировать только явно запрошенную роль через версионированную конфигурацию проекта.

#### Сценарий: разрешённая роль вызывается

- **КОГДА** скилл агента запрашивает включённую роль
- **ТОГДА** используются настроенный провайдер/модель и ограниченный запрос, а метаданные вызова записываются, когда доступны

### Требование: вызовы модели — не оркестрация

CLI модели НЕ ДОЛЖНА рассматриваться как изолированный суб-агент или оркестратор задач.

#### Сценарий: модель возвращает ответ

- **КОГДА** вызов модели без сохранения состояния завершается
- **ТОГДА** главный агент интерпретирует результат; ответ не может независимо изменять код/документы или выполнять инструменты

### Требование: секреты и исходящий трафик контролируются

Система ДОЛЖНА хранить учётные данные вне task.json/репозитория и требовать явной политики для исходящего кода/контекста.

#### Сценарий: настройки провайдера отсутствуют или не разрешены

- **КОГДА** не настроен одобренный endpoint/секрет/политика
- **ТОГДА** опциональная возможность остаётся отключённой; провайдер по умолчанию не выводится

## Не цели / нерешено

Нет собственной среды выполнения мультиагентов, произвольного выполнения инструментов, кастомного прокси, политики провайдера/модели, политики ставок/затрат или схемы вывода.
