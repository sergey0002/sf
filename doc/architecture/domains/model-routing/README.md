# Маршрутизация моделей

## Назначение и граница

Позволить настраиваемую CLI модели и выбор нескольких моделей через OpenAI-совместимые API. Опциональное отображение ролей на модели может маршрутизировать роли, когда собственная поддержка суб-агентов слабая; это настраиваемый вариант реализации одного агента как запасной, а не текущий дизайн мультиагентной оркестрации.

## Принадлежит

- конфигурация CLI модели и контракты совместимости провайдеров;
- граница секретов, конфигурация возможностей на роль/модель и поведение запасного варианта (нерешено).

## Не принадлежит

- выбор модели/провайдера, учётные данные, среда выполнения агента, мультиагентная оркестрация или семантика задач.

## Нерешено

Варианты протоколов провайдера, отказоустойчивость, бюджеты, логирование/политика хранения данных и конфиденциальность требуют явных решений перед реализацией.
