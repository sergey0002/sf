# Тип `refactor`

Изменение внутренней структуры при сохранении наблюдаемого поведения. Зафиксируйте сохраняемые контракты и способ сравнения до и после. Если требуется изменить поведение, уточните scope и подходящий тип задачи.

Используйте YAML типа для обязательных полей и политики подзадач, prompt выбранного flow — для порядка работы. Источники, фиксация проверок и условия закрытия описаны в `doc/AGENTS.md` и `go-to-task`.
