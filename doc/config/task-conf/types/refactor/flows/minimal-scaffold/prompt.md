# Поток `minimal-scaffold` для `refactor`

Следуйте выбранному потоку и возобновляйтесь с первого незавершённого шага. `stageN/` обозначает текущую итерацию.

1. `scaffold` — Проверьте карточку и сохраните короткий baseline поведения.
2. `refactor` — Внесите ограниченное структурное изменение.
3. `verify` — Сравните проверяемое поведение до и после, сохраните результаты.
4. `close` — Сверьте критерии и актуальные результаты, проверьте обязательных детей и зафиксируйте одобрение владельца. Выполните закрытие по `go-to-task`.

Запишите реально выполненные проверки и снимок в `stageN/verification.json`. Устаревшие и неполные результаты требуют повторной проверки.
