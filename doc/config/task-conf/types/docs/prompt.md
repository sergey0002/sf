# Тип `docs`

Изменение документации, инструкций или её конфигурации в указанной области. Найдите канонический источник и сверяйте формулировки с кодом и проверками. Обновляйте затронутые ссылки, метаданные и производный индекс по инструкции architecture-docs.

Используйте YAML типа для обязательных полей и политики подзадач, prompt выбранного flow — для порядка работы. Источники, фиксация проверок и условия закрытия описаны в `doc/AGENTS.md` и `go-to-task`.
