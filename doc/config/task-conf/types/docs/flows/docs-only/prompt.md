# Поток `docs-only` для `docs`

Следуйте выбранному потоку и возобновляйтесь с первого незавершённого шага. `stageN/` обозначает текущую итерацию.

1. `change` — Исправьте нужный документ, скилл или конфигурацию документации и проверьте затронутые ссылки.
2. `validate` — Выполните подходящие структурные проверки. При изменении источников индекса проверьте его свежесть, пересоберите и проверьте результат.
3. `close` — Сверьте критерии и актуальные результаты, проверьте обязательных детей. Примените правила одобрения текущей задачи. Выполните закрытие по `go-to-task`.

Запишите реально выполненные проверки и снимок в `stageN/verification.json`. Устаревшие и неполные результаты требуют повторной проверки.
