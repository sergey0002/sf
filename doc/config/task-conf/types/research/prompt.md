# Тип `research`

Проверяемый ответ на исследовательский вопрос или сравнение подходов. Сформулируйте вопрос и критерии сравнения. Через MOC выберите нужные источники, отделите факты от выводов и укажите ограничения. Запишите короткий результат и рекомендацию.

Используйте YAML типа для обязательных полей и политики подзадач, prompt выбранного flow — для порядка работы. Источники, фиксация проверок и условия закрытия описаны в `doc/AGENTS.md` и `go-to-task`.
