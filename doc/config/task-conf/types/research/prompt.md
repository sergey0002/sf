# Стартовый промпт типа research

Исполняется при начале работы над задачей типа `research`.

## Контекст

Задача — исследование. Нужно собрать информацию, сравнить варианты, задокументировать выводы. Реализация кода не производится без отдельного решения владельца.

## Что сделать

1. Прочитай task.json и этот prompt.md.
2. Выбери flujo `research-first`.
3. Прочитай prompt.md flujo.
4. Запусти `arch task validate <task_key>`.
5. Проведи desk research, составь plan.md с выводами.
6. Подготовь verification.json с рекомендацией.
7. Закрой через `arch task close <task_key>`.
