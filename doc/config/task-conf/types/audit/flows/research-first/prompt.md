# Поток `research-first` для `audit`

Следуйте выбранному потоку и возобновляйтесь с первого незавершённого шага. `stageN/` обозначает текущую итерацию.

1. `audit` — Проверьте согласованные границы и источники. Для каждого наблюдения сохраните точный путь, основание и уровень уверенности.
2. `report` — Сведите подтверждённое, неизвестное и рекомендации. Отметьте пределы покрытия.
3. `close` — Сверьте критерии и актуальные результаты, проверьте обязательных детей. Примените правила одобрения текущей задачи. Выполните закрытие по `go-to-task`.

Запишите результат review или структурной проверки; укажите невыполненные проверки и причины.
