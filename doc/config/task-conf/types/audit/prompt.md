# Тип `audit`

Оценка состояния по заданным вопросам и критериям. Зафиксируйте границы, проверенные источники и наблюдения. Для каждого finding укажите основание, последствия и степень уверенности. Предложите дальнейшие действия. По запросу на аудит подготовьте выводы и отдельные рекомендации к исправлению.

Используйте YAML типа для обязательных полей и политики подзадач, prompt выбранного flow — для порядка работы. Источники, фиксация проверок и условия закрытия описаны в `doc/AGENTS.md` и `go-to-task`.
