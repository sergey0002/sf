# Стартовый промпт типа audit

Исполняется при начале работы над задачей типа `audit`.

## Контекст

Задача — аудит документации, кода или архитектуры. Результат — отчёт с findings и рекомендациями. Автоматическое исправление не производится без одобрения.

## Что сделать

1. Прочитай task.json и этот prompt.md.
2. Выбери flujo `research-first`.
3. Прочитай prompt.md flujo.
4. Запусти `arch task validate <task_key>`.
5. Проведи аудит, составь отчёт с findings.
6. Подготовь verification.json.
7. Закрой через `arch task close <task_key>`.
