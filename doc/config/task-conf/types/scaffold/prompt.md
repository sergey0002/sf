# Тип `scaffold`

Создание рабочего каркаса записи или структуры. Используйте разрешённые пути, проверьте созданную структуру и обязательные поля. Для этого типа подзадачи запрещены.

Используйте YAML типа для обязательных полей и политики подзадач, prompt выбранного flow — для порядка работы. Источники, фиксация проверок и условия закрытия описаны в `doc/AGENTS.md` и `go-to-task`.
