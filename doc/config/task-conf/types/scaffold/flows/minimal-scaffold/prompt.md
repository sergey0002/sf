# Поток `minimal-scaffold` для `scaffold`

Следуйте выбранному потоку и возобновляйтесь с первого незавершённого шага. `stageN/` обозначает текущую итерацию.

1. `scaffold` — Создайте минимальную разрешённую структуру. Если каркас уже существует, проверьте его и заполните недостающие обязательные сведения. Подзадачи не создаются.
2. `close` — Сверьте критерии и актуальные результаты, проверьте обязательных детей. Примените правила одобрения текущей задачи. Выполните закрытие по `go-to-task`.

Запишите результат review или структурной проверки; укажите невыполненные проверки и причины.
