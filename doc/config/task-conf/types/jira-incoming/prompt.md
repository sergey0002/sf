# Стартовый промпт типа jira-incoming

Это стартовый промпт (по принципу скилла), который исполняется при начале работы над задачей типа `jira-incoming`.

## Контекст

Задача поступила из внешнего трекера Jira. Её нужно нормализовать в canonical `task.json`, пройти через единственный flujo процесса `jira-process` и закрыть только после выполнения всех подзадач и получения approval.

## Общие правила

1. `task.json` — единственный canonical input задачи. `task.md` не создаётся.
2. `task_number` — ровно четыре десятичные цифры, выделяется пользователем или утверждённым аллокатором, never automatically.
3. `data/` не редактируется как проектный файл.
4. В `doc/` сохраняются только задекларированные пути из `doc/config/paths.yaml`.
5. CLI детерминирован; семантические решения — за агентом/скиллом.

## Что сделать сначала

1. Прочитай `task.json` и `config.yaml` этого типа.
2. Убедись, что `source.type == "jira"` и `task_key` — bare four-digit number (без префикса).
3. Запусти `arch task validate <task_key>`.
4. Запусти `arch docs paths --check`.
5. Перечитай flujo `jira-process` и следуй его `prompt.md`.

## Закрытие

Задача закрывается через `arch task close <task_key>` только если все подзадачи имеют `phase: completed` и получен approval владельца.
