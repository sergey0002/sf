# Тип `jira-incoming`

Локальная обработка задачи с подтверждённым источником Jira. Сохраните идентификатор и происхождение входа. Прочитайте локальный снимок, отметьте недостающие данные и проверьте обязательные подзадачи. Действия во внешнем трекере выполняются по отдельному разрешению.

Используйте YAML типа для обязательных полей и политики подзадач, prompt выбранного flow — для порядка работы. Источники, фиксация проверок и условия закрытия описаны в `doc/AGENTS.md` и `go-to-task`.
