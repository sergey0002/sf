# Поток `jira-process` для `jira-incoming`

Следуйте выбранному потоку и возобновляйтесь с первого незавершённого шага. `stageN/` обозначает текущую итерацию.

1. `intake` — Проверьте локальный снимок Jira, ключ, актуальность входа и границы работы. При конфликте источников уточните scope.
2. `plan` — Свяжите критерии, подзадачи и проверки; зафиксируйте согласование владельца.
3. `implement` — Выполните согласованный срез. Обновление внешнего трекера выполняется по отдельному разрешению.
4. `verify` — Проверьте итоговый снимок против критериев задачи. Провал возвращает к реализации.
5. `close` — Сверьте критерии и актуальные результаты, проверьте обязательных детей и зафиксируйте одобрение владельца. Выполните закрытие по `go-to-task`.

Запишите реально выполненные проверки и снимок в `stageN/verification.json`. Устаревшие и неполные результаты требуют повторной проверки.
