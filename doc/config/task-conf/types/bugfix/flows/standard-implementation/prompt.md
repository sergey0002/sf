# Поток `standard-implementation` для `bugfix`

Следуйте выбранному потоку и возобновляйтесь с первого незавершённого шага. `stageN/` обозначает текущую итерацию.

1. `reproduce` — Воспроизведите исходный симптом или зафиксируйте, почему это невозможно и какое основание доступно.
2. `plan` — Опишите границу исправления, критерий приёмки и регрессионную проверку. Зафиксируйте требуемое согласование.
3. `fix` — Внесите ограниченную правку и подготовьте регрессионную проверку.
4. `verify` — Проверьте исходный сценарий и затронутые контракты. Провал возвращает к исправлению.
5. `close` — Сверьте критерии и актуальные результаты, проверьте обязательных детей и зафиксируйте одобрение владельца. Выполните закрытие по `go-to-task`.

Запишите реально выполненные проверки и снимок в `stageN/verification.json`. Устаревшие и неполные результаты требуют повторной проверки.
