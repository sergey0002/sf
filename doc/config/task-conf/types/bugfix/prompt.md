# Тип `bugfix`

Устранение конкретного дефекта с проверяемым симптомом. Запишите ожидаемое и фактическое поведение. По возможности воспроизведите исходный симптом и подготовьте регрессионную проверку. Если воспроизведение не удалось, обозначьте ограничение и согласуйте достаточный критерий проверки.

Используйте YAML типа для обязательных полей и политики подзадач, prompt выбранного flow — для порядка работы. Источники, фиксация проверок и условия закрытия описаны в `doc/AGENTS.md` и `go-to-task`.
