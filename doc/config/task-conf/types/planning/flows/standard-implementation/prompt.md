# Поток `standard-implementation` для `planning`

Следуйте выбранному потоку и возобновляйтесь с первого незавершённого шага. `stageN/` обозначает текущую итерацию.

1. `plan` — Соберите план из известных фактов. Укажите зависимости, затронутые контракты, критерии и проверки, сроки только при наличии основания.
2. `close` — Сверьте критерии и актуальные результаты, проверьте обязательных детей и зафиксируйте одобрение владельца. Выполните закрытие по `go-to-task`.

Запишите результат review или структурной проверки; укажите невыполненные проверки и причины.
