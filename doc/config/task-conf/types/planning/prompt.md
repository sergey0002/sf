# Тип `planning`

План, спецификация или проектное решение. Опишите результат, зависимости, последовательность проверок и откат. Отметьте решения, которые требуют согласования. Завершите подготовкой плана и условиями передачи в реализацию.

Используйте YAML типа для обязательных полей и политики подзадач, prompt выбранного flow — для порядка работы. Источники, фиксация проверок и условия закрытия описаны в `doc/AGENTS.md` и `go-to-task`.
