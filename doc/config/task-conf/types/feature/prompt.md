# Тип `feature`

Новое или изменённое наблюдаемое поведение. Свяжите условия приёмки с требованиями и тестами. Действующая политика требует подзадач с проверяемыми результатами. Выберите стандартную реализацию либо исследование с рекомендацией согласно цели выбранного потока.

Используйте YAML типа для обязательных полей и политики подзадач, prompt выбранного flow — для порядка работы. Источники, фиксация проверок и условия закрытия описаны в `doc/AGENTS.md` и `go-to-task`.
