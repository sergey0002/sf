# Сбор архитектурного контекста

**Вход.** Карточка, текущий `stageN/plan.md`, `related_docs`, `project_context_refs` и затронутые AC. Возьмите пути из `arch task diagnose <key> --json --brief`, если ещё открываете задачу.

**Действие.** Примените `architecture-read`. По `arch list --id <id> --json` найдите путь записи и прочитайте только применимый раздел. Возьмите ограничение манифеста или проекта, сохраняемое поведение и связанный отказ или побочный эффект. Расширяйте чтение по конкретному пробелу.

**Результат.** Запишите в плане `ID и раздел → правило → сохранить или изменить → AC, CASE или проверка`. Если раздел отсутствует, укажите альтернативный источник. Перед `plan` проверьте разрешение конфликтов, которые меняют требования или scope.
