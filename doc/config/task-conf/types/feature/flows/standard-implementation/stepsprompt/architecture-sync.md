# Синхронизация архитектурной документации

**Вход.** Правила из `stageN/plan.md`, ограниченный diff и результат целевого прогона.

**Действие.** Примените `architecture-docs`. При подтверждённом изменении контракта обновите ближайшую каноническую запись и затронутый справочник. При сохранении контракта запишите короткое основание. Если реализация нарушает сохраняемое правило, вернитесь к `implement`.

**Результат.** Сохраните в плане ID, точный раздел и связанный AC или CASE либо основание отсутствия дельты. На `verify` проверьте архитектурную запись и фактическое поведение вместе. Включите изменённые документы в проверенный снимок.
