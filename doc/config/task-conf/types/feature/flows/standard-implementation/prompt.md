# Поток `standard-implementation` для `feature`

Следуйте выбранному потоку и возобновляйтесь с первого незавершённого шага. `stageN/` обозначает текущую итерацию.

1. `intent` — Проверьте наблюдаемый результат и критерии приёмки, уточните блокирующие вопросы.
2. `plan` — Подготовьте план, самостоятельные результаты подзадач и проверки. Зафиксируйте требуемое согласование.
3. `implement` — Работайте в границах scope. Обновите затронутые контракты и тесты.
4. `verify` — Сопоставьте проверки с критериями и итоговым снимком. Провал возвращает к реализации.
5. `close` — Сверьте критерии и актуальные результаты, проверьте обязательных детей и зафиксируйте одобрение владельца. Выполните закрытие по `go-to-task`.

Запишите реально выполненные проверки и снимок в `stageN/verification.json`. Устаревшие и неполные результаты требуют повторной проверки.
