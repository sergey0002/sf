# Поток `research-first` для `feature`

Следуйте выбранному потоку и возобновляйтесь с первого незавершённого шага. `stageN/` обозначает текущую итерацию.

1. `research` — Сравните варианты реализации по критериям задачи. Сохраните ссылки, допущения и ограничения.
2. `recommend` — Запишите рекомендацию, последствия и условия передачи в реализацию. Этот поток завершается исследовательским результатом; реализацию согласуйте отдельно.
3. `close` — Сверьте критерии и актуальные результаты, проверьте обязательных детей и зафиксируйте одобрение владельца. Выполните закрытие по `go-to-task`.

Запишите результат review или структурной проверки; укажите невыполненные проверки и причины.
