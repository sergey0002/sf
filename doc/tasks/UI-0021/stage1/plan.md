## Шаги

1. Описать владельца проверок, допустимую локальную среду и критерии остановки.
2. Запускать заранее заданные проектные проверки, сохранять результат ревизии и состояние прерванного прогона.

## Подзадачи

- `0001` — Ограниченный жизненный цикл локального прогона
- `0002` — Запись результата и независимая приёмка

## Приёмка

- AC-1: Настроенный прогон имеет ограниченные ресурсы и восстанавливается после прерывания.
- AC-2: Результат связан с проверенной ревизией и версией проверок; защищённые критерии остаются доступны независимой приёмке.

Перед изменениями зафиксировать исходный результат. Для каждого AC записать фактическую проверку и проверенный снимок в `verification.json`. Базовые команды указаны в записи верификации. Проверки предметного сценария выполнить по критериям выше.
