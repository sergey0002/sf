# UI-0030-0001: Типы, политики и проверки CLI

## Цель

Публичные команды принимают предметную форму и не пишут частичный пакет при нарушении политики. Вход: YAML из `doc/config/task-conf/types/`, корневая fixture `UI-9999`, [план родителя](../../../stage1/plan.md) и его CASE-1–5. Граница записи: `doc/tools/arch/`, `doc/config/task-conf/`, `doc/config/paths.yaml`, контрактные тесты.

## Правила проекта

`FLOW-cli-subtask-lifecycle`, `init/validate/status`: сохранить ключи, пути и семантику каркаса. `ARCH-contract`, task-conf: один источник иерархии. `ENT-task-record`, «Инварианты»: не менять сохранённые журналы и intent вне существующих переходов.

## Решения и порядок

Сначала закрепить фикстуры и общий preflight под блокировкой. Затем провести тип, flow и сложность в обе команды и применить роль при валидации. Разделить новую постановку и точное возобновление; не переписывать реальные карточки. Срез откатывается возвратом собственных изменений конфигов, CLI и тестов.

## Приёмка

| CASE | AC | Дано / действие | Ожидание и независимая проверка |
|---|---|---|---|
| CASE-1 | AC-1 | Fixture F и точные вызовы CASE-1 родителя | Exit 0; прямое чтение task.json даёт `research/research-first`, записи родителя изменены только пакетной командой. |
| CASE-2 | AC-1, AC-2 | Точные отрицательные вызовы CASE-2 родителя | Exit 2 с причиной; байты всего дерева прежние. |
| CASE-3 | AC-2 | Матрица `scaffold` / корень и лист `feature` из CASE-3 родителя | Запрет пишет только диагностику; feature-ребёнок валиден, корень без детей невалиден. |
| CASE-4 | AC-2 | Старый журнал, повтор после каждой границы, конфликт, порча и конкуренция из CASE-4–5 родителя | Exit 0 при точном повторе без дубликатов; exit 5 без изменения дерева в отказных случаях. |

## Оценка

16 ч, `medium`: политики и выбор формы 6 ч, preflight и возобновление 4 ч, проверки 6 ч. Подзадач нет: результат один, проверяется через общий вход CLI.

## Проверка

`python3 -m unittest discover -s doc/tests -p test_task_identity.py`, ожидается exit 0. Снимок: CLI, YAML, тесты и этот план.
