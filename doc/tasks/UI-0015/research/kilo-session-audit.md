## Предложения по workflow

Приоритет — что убрать из контекста и что отдать CLI. Проверка выигрыша: тот же AC-1/AC-2, чистый checkout, сравнение input и `cache_read` до первой целевой команды и доли провалов tools.

1. **CLI, высокий.** Команда `arch baseline run --scenario <id> --json` сама выполняет объявленные шаги, пишет `duration_ms`, точные `stdout_bytes`/`stderr_bytes`, exit, `git rev-parse HEAD` и sha256 затронутых файлов. Агент не переписывает числа. Выигрыш: исчезает класс ложных baseline (пустой хеш, круглые байты, чужая причина падения). Покрытие AC-2 сохраняется, потому что сценарий остаётся данными, а не рассказом.

2. **Skill `go-to-task`, высокий.** Для docs-задачи запретить полный `write` каталога до прохождения объявленных шагов и требовать в `verification.json` пару «команда сценария = команда прогона». Сейчас шаг 4 в README и в baseline разные, и это не ловится. Проверка: фикстура с заведомо битым якорем должна дать `result=fail`, а не `partial` + `stage completed`.

3. **CLI `docs paths`, высокий.** `paths --check` должен печатать конкретный неразрешённый путь и не принимать дубли строк. Сессия трижды гоняла проверку и добавила `task_record.py` дважды, плюс `state.json`/`events.jsonl` вне AC. Проверка: повторный `--check` после одной точечной строки baseline.

4. **Skill / AGENTS, средний.** Вход «подготовся» не должен читать все `SKILL.md` и весь `nextplan.md`. Достаточно `task diagnose --brief`, карточки и секций «когда загружать» через `rg` или `--help`. Ожидаемый эффект на этой сессии: минус ~54 КБ roadmap и ~8 полных скиллов до первой записи. Проверка: подготовка UI-задачи укладывается в diagnose + 1 карточка + каталог, без `read` каждого SKILL.md.

5. **CLI `session digest`, средний.** В `anomalies` добавить метку `evidence-mismatch`: строка команды в `verification.json` отсутствует среди успешных `tool_calls`. Это сразу показало бы `#entities` против `#жизненный-цикл-задачи`. Проверка: digest этой сессии содержит mismatch по AC-2.

6. **Flow `docs-only`, низкий.** Явный шаг «не расширять `allowed_paths` ради артефакта, пока AC не требует новый корень». Паттерн `doc/tests/baseline/{slug}.json` уместен; `task migrate` и `task_record.py` — нет. Проверка: diff `paths.yaml` в docs-задаче ограничен путём нового артефакта.
