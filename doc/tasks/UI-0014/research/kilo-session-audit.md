## Повторная оценка после доработки

Выполнены улучшения по пунктам аудита:

1. Версия имеет один источник: `dynamic = ["version"]` + `attr = "arch.__version__"`; unit-тест запрещает статическую версию.
2. `--index-only` строит индекс дважды с `PYTHONHASHSEED=0` и `PYTHONHASHSEED=12345` в разных временных деревьях и сравнивает обе сборки с `index.json` и между собой. Добавлен acceptance-тест, который ломает детерминизм по seed и требует отказа.
3. `task evidence` принимает ключ ребёнка; evidence родителя и детей записан командами `arch task evidence --run`, а не вручную.
4. `run.sh --in-copy` инкапсулирует проверку в изолированной копии и не меняет checkout; acceptance-тест подтверждает это на снимке без `kilo.jsonc`.
5. CI сведён к `run.sh --ci` плюс сборка wheel и установка вне checkout с проверкой версии и `--root list`; YAML и шаги проверены локально.
6. `UI-0014` переведена на `acceptance_policy: case-coverage-v1`; `planned_checks` покрывают оба AC, `task diagnose` показывает `acceptance_plan_ready: true`.

Повторная оценка: **реализация 10/10**, процесс 9/10. Оставшееся снижение процесса — невозможность исполнить GitHub Actions в песочнице и один неподдержанный вызов `task evidence` до добавления ключа ребёнка. Внешние ограничения (зависимость `UI-0012`, переименованный `kilo.jsonc`) не относятся к качеству реализации.
