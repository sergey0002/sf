# UI-0029-0002: CLI продуктовых флоу

## Цель
Дать агенту компактный пакет контекста и проверяемое влияние изменений. Вход: принятая модель и эталон P из `0001`; команды и данные B/D заданы в [плане родителя](../../../stage1/plan.md#приёмка).

## Правила проекта
`CAP-addressable-contracts#read`, `#context`, `#impact`, `#invariants`: чтение ограничено, связь доказуема и не предоставляет полномочий.

## Решения и порядок
В `doc/tools/arch/` добавить загрузку за JSON-схемой, индекс стабильных веток и типизированных ссылок. Подключить `docs search/read/context/impact/check-links` и представления `docs flow`. Проверку ссылки на код по точному символу применять только там, где известен поддерживаемый источник символов; если источник недоступен, возвращать непроверенную ссылку, а не считать её валидной. Поведение прежних команд без новых флагов оставить прежним. Контракт вывода записать в `doc/architecture/system/addressable-contracts.md`, оракулы в `doc/tests/test_doc_contracts.py`.

## Риски и откат
Не превращать текстовые совпадения в подтверждённое влияние, не запускать команды из ссылок. При отказе дерево не меняется. Можно отключить JSON-чтение и восстановить производный индекс, не трогая источники.

## Приёмка
| CASE | AC | Дано | Действие | Ожидание и проверка | Ребёнок |
|---|---|---|---|---|---|
| CASE-3 | AC-1 | P с `billing.refund`, затем малый бюджет | Search, read и decisions по родительским вызовам | Известные ID и причины, один запрошенный раздел, пустой поиск явно пуст; усечение содержит `complete: false` и `omitted` | нет |
| CASE-4 | AC-3 | P с битой обязательной ссылкой, конфликтом применимости и дубликатом в отдельных копиях | `docs check-links --json`, `docs read` | Нет угадывания; exit 1 с ID, точным путём и причиной; снимок не изменён | нет |
| CASE-5 | AC-2 | B и рабочий D | `docs impact --since <B> --scope all --flows --json` | Дельта и межмодульная связь совпадают с эталоном родителя; непокрытый путь не скрыт, дерево не изменилось | нет |
| CASE-6 | AC-3 | Перенесённые корни с JSON и прежним Markdown | `docs read` под `--root`/`--config`; сравнить Markdown с baseline | Правильные относительные ссылки, прежние данные и exit для Markdown | нет |

## Оценка
16 ч: 5 ч индекс, 6 ч чтение и контракты, 5 ч анализ и сценарии. Дочерних задач нет.

`python3 -m unittest doc.tests.test_doc_contracts -q`. Сравнить эталонные ID, постусловия и хеши, проверить ограничения выдачи на множестве несвязанных веток.
