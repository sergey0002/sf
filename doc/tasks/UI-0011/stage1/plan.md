# UI-0011 — Готовность закрытия

Статус: запланировано. Выпуск дорожной карты: v0.1.
Источник: `nextplan.md` §15, 17, 21–22 и §24, пакет P01.
Зависимости: нет.

## Объём

- doc/tools/arch/
- doc/tests/
- doc/architecture/

## Шаги

1. Воспроизвести закрытие при объявленном, но отсутствующем ребёнке на временной записи.
2. Объединить проверку готовности, добавить предпросмотр и согласовать JSON отказа.

## Приёмка

- AC-1: diagnose и close указывают один отсутствующий ID; отказ и dry-run сохраняют исходную запись побайтно.
- AC-2: Совместимая валидная задача без обязательных детей закрывается; CLI-тест проверяет код процесса и JSON.

Перед изменениями зафиксировать исходный результат. Для каждого AC записать фактическую проверку и проверенный снимок в `verification.json`. Базовые команды указаны в записи верификации. Проверки предметного сценария выполнить по критериям выше.
