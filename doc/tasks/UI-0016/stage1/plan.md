## Шаги

1. Описать владеющие поля intent, flow version, state и event, затем совместимый формат.

## Подзадачи

## Приёмка

- AC-1: Старые записи читаются, миграция повторяема, исходный intent сохраняется.
- AC-2: Повтор события не создаёт вторую запись, конфликт ревизии отклоняется, replay восстанавливает состояние.

Перед изменениями зафиксировать исходный результат. Для каждого AC записать фактическую проверку и проверенный снимок в `verification.json`. Базовые команды указаны в записи верификации. Проверки предметного сценария выполнить по критериям выше.
