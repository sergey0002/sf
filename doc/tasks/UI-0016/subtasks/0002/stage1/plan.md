- doc/config/
- doc/tools/
- doc/tests/

## Шаги

1. Реализовать проверку ревизии, ключ повторения и восстановление состояния.
2. Проверить повтор, конфликт, прерванную запись и повреждённый журнал.

## Приёмка

- AC-1: Сбой, повтор и конфликт ревизии покрыты проверками.

## Проверка

- CASE-1: повтор события не создаёт запись; неверная ревизия и тот же ключ с другим содержимым отклоняются; replay восстанавливает состояние, повреждённый журнал не материализуется.

## Результат

Реализация находится в `doc/tools/arch/task_record.py`. Проверка записана в `verification.json`. Зависимость `UI-0016-0001` и `UI-0013` блокируют закрытие.

Перед изменениями зафиксировать исходный результат. Для каждого AC записать фактическую проверку и проверенный снимок в `verification.json`. Базовые команды указаны в записи верификации. Проверки предметного сценария выполнить по критериям выше.
