## Шаги

1. Описать таблицу выбора и два YAML flow: bugfix и docs-only.
2. Реализовать вычисление переходов, готовности детей и диагностику ошибок схемы.

## Подзадачи

- `0001` — Формат flow и статические проверки
- `0002` — Переходы и готовность подзадач

## Приёмка

- AC-1: Багфикс проходит возврат verify → fix; docs-only завершается коротким путём без детей.
- AC-2: Неизвестный вход, конфликт правил, циклы и битые ссылки дают явные причины; отклонённое событие не меняет состояние.

Перед изменениями зафиксировать исходный результат. Для каждого AC записать фактическую проверку и проверенный снимок в `verification.json`. Базовые команды указаны в записи верификации. Проверки предметного сценария выполнить по критериям выше.
