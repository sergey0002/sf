# UI-0024 — Решение о расширениях после пилота

Статус: запланировано. Выпуск дорожной карты: после пилота.
Источник: `nextplan.md` §7–10, 20 и §24, пакет P14.
Зависимости: `UI-0022`.

## Объём

- doc/tasks/
- doc/architecture/

## Шаги

1. Оценить аллокатор, workflow engine, каталоги, model routing и расширение автономности по данным пилота.
2. Записать условия включения, владельца решения и метрику.

## Приёмка

- AC-1: Для каждого расширения есть наблюдаемая предпосылка и решение о постановке или откладывании.
- AC-2: Выбранные расширения имеют измеримую гипотезу, границы и следующую задачу.

Перед изменениями зафиксировать исходный результат. Для каждого AC записать фактическую проверку и проверенный снимок в `verification.json`. Базовые команды указаны в записи верификации. Проверки предметного сценария выполнить по критериям выше.
