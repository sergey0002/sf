# UI-0013 · Уточнение гарантий восстановления

Исходная приёмка и замечания восстановлены по [аудиту Kilo](../research/kilo-session-audit.md). Исходные AC в карточке сохраняются. Контракт задают раздел «Устойчивая запись и восстановление» `SPEC-cli-implementation` и карта команд `REG-cli-command-map`.

## Правила проекта

- У одного родителя повторяемая составная операция публикует намерение перед изменением записей. Любой обнаруживаемый конфликт обязан сохранить дерево. Проверяется `CASE-1` и `CASE-2`.
- Повтор валидного пакета завершает недостающие записи, сохраняя уже подтверждённые записи. Точка поддержки — остановка процесса на локальной POSIX ФС. Проверяется `CASE-3` и `CASE-4`.
- Переходящие через CLI писатели одного родителя координируются блокировкой каталога. Матрица сохраняет совместимые ответы команд. Проверяется `CASE-5` и `CASE-6`.

## Приёмка

| CASE | Критерий | Дано и действие | Ожидаемый результат |
|---|---|---|---|
| CASE-1 | AC-1 | Некорректный новый пакет, свежая коллизия или валидный журнал с конфликтом у последнего ребёнка. Запустить `decompose`. | Отказ. На конфликте exit 5, все пути и байты дерева совпадают. |
| CASE-2 | AC-1 | Журнал с обрывком JSON, неподходящим типом или пустым пакетом. Вызвать `diagnose`, `status`, `scan`, предпросмотр и мутирующие команды. | Диагностика отмечает `invalid`, `would_close: false`, команды записи отказывают, дерево совпадает. |
| CASE-3 | AC-1 | До публикации журнала остался временный файл, либо процесс остановлен при записи ребёнка после `fsync` и до `os.replace`. Повторить пакет. | Дочерние записи целы, ровно один набор объявлений в родителе, остатков и журнала нет. |
| CASE-4 | AC-1 | Валидный журнал с полностью созданным, частичным и отсутствующим ребёнком либо уже заменённым родителем. Повторить тот же пакет, отдельно проверить несовпадающий пакет. | Те же записи дозавершаются без дублей. Повтор после записи родителя сохраняет его байты. Другой пакет получает отказ без записи. |
| CASE-5 | AC-1 | Держать блокировку каталога родителя. Вызвать `decompose`, `close` и `subtask init` из другого процесса. | Exit 5 и неизменное дерево. После освобождения повтор проходит. |
| CASE-6 | AC-2 | Запустить старые запросы task-conf, создание пакета, диагностику и `close` с `--json`, включая отказ. | Привычные выходы и семантические коды сохраняются. Формат состояния `invalid` добавлен только к диагностике повреждённого журнала. |

Целевые сценарии проверяются через фактический CLI на временных корнях. Полный компактный прогон выполняется на итоговом снимке. Результаты, команды и хеши сохраняются в `verification.json`.
