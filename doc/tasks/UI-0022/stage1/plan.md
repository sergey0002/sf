## Шаги

1. Задать репозиторий и критерии приёмки, бюджет, правила остановки и отката.
2. Сравнить одинаковые задачи на закреплённых версиях фабрики, OpenSpec, Spec Kit и совместного сценария.

## Приёмка

- AC-1: Пилот проводится в согласованных границах с проверенным восстановлением.
- AC-2: Отчёт фиксирует версии, выборку, корректность, стоимость и разброс; выводы ограничены сценарием.

Перед изменениями зафиксировать исходный результат. Для каждого AC записать фактическую проверку и проверенный снимок в `verification.json`. Базовые команды указаны в записи верификации. Проверки предметного сценария выполнить по критериям выше.
