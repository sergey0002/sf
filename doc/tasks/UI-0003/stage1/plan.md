1. **Перечитать манифест** — разделы о CLI, скилах, задачах, архитектуре, four layers, E2E flow.
2. **Перечитать data/ через MOC** — data/README.md → Главная/Индекс каждой энциклопедии → целевые страницы о CLI, скилах, SDD, задачах, архитектуре.

4. **Составить анализ CLI-команд** — группы: задачи (task.json), архитектура (документы, индекс, валидация, ADR), планирование (stages, deltas), data/ (справочник).
5. **Составить анализ скилов** — существующие (create-task, go-to-task, задокументируй) + необходимые новые (планирование, архитектурные решения, работа с data/).
6. **Описать принятые решения и обоснования** — ссылки на манифест и data/.
7. **Создать /home/user/cli.skill.plan.md** — полное описание CLI + скилов.
8. **Прогнать тесты** — doc/tests/run.sh 13/13.
