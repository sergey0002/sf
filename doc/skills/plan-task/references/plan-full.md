# Шаблон плана: `full`

Для `complexity: high|critical`, больше 24 часов, необратимого изменения или нескольких стадий. Обязательны все разделы; разделы по риску добавляются по условию.

## Что обязательно

- Маркер `<!-- plan-tier: full -->` первой строкой.
- Заголовки, содержащие `Цель`, `Правила проекта`, `Решения`, `Риск`, `Приёмка`, `Оценка`, `Проверка`.
- Каждый AC покрыт `CASE` с независимым оракулом.
- Порядок работ, зависимости, границы прерывания и откат.
- Оценка часов и обоснованная декомпозиция.

## Дополнительные разделы по риску

| Условие | Раздел |
|---|---|
| Формат данных или публичный контракт | `## Контракты данных` — схема, поля, совместимость, миграция |
| Многошаговая запись | `## Границы прерывания` — состояние до/после, повтор, конфликт, повреждённый журнал |
| Внешние вызовы или секреты | `## Безопасность` — границы доверия, таймауты, отсутствие секретов в логах |
| Производительность | `## Производительность` — измеримая цель и способ замера |
| Наблюдаемость | `## Наблюдаемость` — события, поля, уровни |
