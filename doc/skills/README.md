# Скиллы фабрики

Эти инструкции хранятся в проекте. В среде, которая не обнаруживает их автоматически, открывайте нужный `SKILL.md` по маршруту из [doc/AGENTS.md](../AGENTS.md).

В Kilo пути скиллов зарегистрированы в [kilo.jsonc](../../kilo.jsonc). Для диагностики задачи или предпросмотра выберите `factory-operator` в новой сессии. Он ограничивает чтение реализации Arch CLI и разрешает задокументированные команды чтения. Режим `code` подходит для изменений CLI. [Загрузка инструкций в Kilo](https://kilo.ai/docs/customize/agents-md) · [Права инструментов](https://kilo.ai/docs/customize/agent-permissions)

| Скилл | Когда применять | Результат |
|---|---|---|
| [arch-cli](arch-cli/SKILL.md) | Использовать CLI для чтения, проверок, индекса или работы с карточкой | Нужная команда, формат ответа, условие записи и следующий шаг |
| [create-task](create-task/SKILL.md) | Зарегистрировать новую задачу или декомпозицию | Валидная карточка, план, зависимости и намеченные проверки |
| [go-to-task](go-to-task/SKILL.md) | Выполнить, продолжить или проверить задачу по точному ключу | Проверяемое изменение и фактическое evidence либо точный блокер |
| [review-implementation](review-implementation/SKILL.md) | Проверить diff и AC на стабильном снимке | Воспроизводимые находки или проверенные сценарии и границы ревью |
| [architecture-read](architecture-read/SKILL.md) | Выполнить `architecture-context` или найти применимые правила при постановке задачи | Точные ID и разделы, инварианты и связь с AC или CASE |
| [architecture-docs](architecture-docs/SKILL.md) | Выполнить `architecture-sync` или задачу `docs-only` | Проверенная дельта канонической документации или основание её отсутствия |
| [задокументируй](document-session/SKILL.md) | Зафиксировать подтверждённые факты или решения сессии | Обновление стадии или целевого документа по источникам |
| [kilo-session-audit](kilo-session-audit/SKILL.md) | Найти прошлую сессию Kilo, провести универсальный аудит результата, процесса и достаточности архитектуры | Дайджест с метками и доказательствами, оценки, блокеры и адресные рекомендации по flow, скиллам, правилам и CLI |
